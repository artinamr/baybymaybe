## Found while verifying the changes

**Phones loaded the home page zoomed out.** Before the layout script ran,
the hero's lines used their desktop fallback sizes (POTENTIAL ≈ 1350 px
wide). On a phone that widened Chrome's layout viewport to 1356 px; the
hero was laid out for that width and shrank back in ~8 % steps over
~2.5 s (the canvas, re-sized each step, fed the loop). It also made
`?at=` look-dev landings ×3 too far on phones. Fixed with
`.hero-h1 { overflow: clip }` — `innerWidth` is 390 from the first frame;
desktop film stills unchanged.
